# VerityData Claude Plugin

**Analyst-grade insider intelligence, directly in Claude.**

This plugin connects Claude to [VerityData](https://www.verityplatform.com) (InsiderScore) via MCP and ships eight skills that transform raw insider transaction data into polished tables, charts, and dashboards — no copy-paste, no context-switching.

---
## Prerequisites

- A [Claude.ai](https://claude.ai) account (Pro, Team, or Enterprise)
- A VerityData / InsiderScore account with MCP access
- A VerityData/InsiderScore account with MCP access — Claude will prompt you to sign in on first use. Contact datafeeds@verityplatform.com to have MCP access enabled on your account.
